# Knowledge bank (kb)

Every task output is saved here as a Markdown file, so the team and every agent can find what we learned.

## Rules
- One file per output, in your own subfolder: `kb/rashed/`, `kb/hakim/`, `kb/vinzenz/`.
- File name: `<task-id>-<short-name>.md`, for example `kb/vinzenz/V1-bafu-lca-grid-mix.md`.
  Research without a task id: `notes-<short-name>.md`.
- Start each file with: task, author, date, status (draft / final) and sources.
- Numbers that end up in the app, templates or pitch still come only from `out/` (AGENTS.md rule 2).
  A kb file explains and sources them; it does not replace the pipeline.
- Machine-readable files the pipeline needs (for example `factors/factors.csv`) stay where they are;
  the kb file links to them.
- Add your file to the index below in the same pull request.
